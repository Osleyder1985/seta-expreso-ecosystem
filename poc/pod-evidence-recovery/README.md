# POD Integrated Recovery PoC

PoC sintético para validar metadata, contenido, hash y referencias de almacenamiento.

Dataset: 30 PhysicalBulto, 30 Evidence metadata, 30 contenidos sintéticos y 3 tipos.

Escenarios: R01 backup; R02 restore; R03 ausencia; R04 corrupción; R05 metadata sin objeto; R06 objeto huérfano; R07 restore repetido; R08 fallo parcial y reparación; R09 verificación; R10 inventario.

No utiliza datos reales ni selecciona proveedor de producción.
