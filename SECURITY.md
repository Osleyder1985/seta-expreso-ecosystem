# Seguridad

No publiques secretos, credenciales, datos personales ni vulnerabilidades explotables en Issues publicas.

Cuando GitHub Private Vulnerability Reporting o Security Advisories esten habilitados, usa ese mecanismo para reportes sensibles. Si no esta disponible, contacta al propietario del repositorio mediante un canal privado de GitHub.

Los controles de seguridad deben respaldarse con evidencia reproducible en CI, PoC o pruebas de integracion segun la fase del componente.

Nunca almacenes credenciales reales en workflows, configuracion, PoCs o documentacion.
