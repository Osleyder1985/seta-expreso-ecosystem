# Gobierno del repositorio

Este documento establece la puerta de entrada documental del repositorio SETA EXPRESO SURL.

El estado actual es ingeniería, arquitectura y validación experimental. El producto Web/Android/iOS todavía no está integrado como producto productivo.

Estructura: `docs/software-engineering`, `docs/architecture`, `docs/domain`, `docs/governance`, `docs/audit`, `docs/security`, `docs/technology` y `poc`.

Flujo: Issue → evidencia → decisión/ADR → implementación → pruebas → PR → CI → revisión → integración → verificación.

La auditoría vigente se encuentra en `docs/audit/software-engineering-ecosystem-audit-v2.0.0.md`.
