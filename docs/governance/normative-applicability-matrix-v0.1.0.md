## Regla de interpretación

La inclusión de una norma no implica certificación ni conformidad. La aplicabilidad se determina por proceso, dato, actor, obligación y fase del ciclo de vida. La ausencia de evidencia se registra como pendiente de evaluación, no como incumplimiento automático.

## Reglas de actualización

1. Registrar edición y fuente oficial.
2. Registrar fecha de verificación.
3. Determinar aplicabilidad por proceso.
4. Relacionar cada requisito aplicable con control y evidencia.
5. Separar requisitos jurídicos de estándares voluntarios.
6. No declarar conformidad por mera existencia de documentación.
7. Revisar cuando cambie la edición, el proceso o el marco jurídico.

## Próximo nivel

La siguiente evolución será una matriz artículo/requisito → obligación → control → evidencia → responsable → prueba → estado, cuando el proceso productivo y sus tratamientos de datos estén definidos.
